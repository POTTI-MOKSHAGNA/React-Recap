# Notes App 📝

## Overview

Notes App is a React-based application that allows users to create, edit, update, and manage notes efficiently.

The project was built to practice React state management, form handling, component communication, and CRUD-style operations.

---

## Features

* Create Notes
* Edit Existing Notes
* Update Notes
* Delete Notes
* Dynamic Note Rendering
* Responsive User Interface

---

## Tech Stack

* CSS
